# 配置与使用指南

### 扫描规则与正则库

钩子在 `pre-commit` 和 `pre-push` 阶段运行以下深度检查：
1. **高危凭证检测**：匹配 OpenAI (`sk-...`)、Anthropic (`sk-ant-...`)、GitHub Token (`ghp_...`)、私钥块 (`BEGIN PRIVATE KEY`) 等 40+ 常见格式；
2. **拓扑与非路由探测**：拦截真实公网 IPv4 字面量与内部专网域名；
3. **占位符放行机制**：自动放行 RFC 2606 / RFC 6761 保留域名（如 `example.com`、`example.test`）。

---

## 生产部署建议

1. **环境变量保护**：切勿将包含真实密钥或 Token 的配置提交至版本库；
2. **优雅停机与超时**：建议将关键长任务的超时时限设置为合理范围，避免僵尸进程驻留；
3. **日志监控**：结合控制台输出建立定期检查机制，捕获潜在异常。
