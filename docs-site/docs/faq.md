# 常见问题与排错

以下汇总了日常使用与开发集成过程中最常见的问题解答：

### Q: 我的代码注释里需要写一个示例 Token，会被拦截吗？

**A**: 会被拦截，除非将其格式化为标准的占位符格式（例如 `sk-ant-api03-xxx...`），规范的占位符能有效防止安全误判。

### Q: 确需在测试夹具中写入模拟哈希该怎么办？

**A**: 可以将测试用例文件添加至 `EXEMPT_PATHS` 例外白名单中，或在提交信息的首行顶格标注跳过指令。

## 故障排查通用步骤

1. **核对运行环境版本**：确保您的 Node.js / Python 或浏览器版本符合最低兼容要求；
2. **检查控制台报错日志**：绝大部分配置错误或权限拒绝在控制台中都有清晰的行号与原因提示；
3. **提交 Issue 反馈**：若确认遇到底层 Bug，欢迎前往 GitHub 仓库提交复现用例与诊断日志。
